# Структура презентації проєкту "Game Diary" (5-7 хв)

1. **Титульний слайд:** Назва проєкту, автор (Ігор Стасюк), курс ІПЗ.
2. **Проблема та мета:** Відсутність зручного мінімалістичного трекера для пройдених ігор. Мета — створити швидкий мобільний щоденник.
3. **Вимоги (User Stories):** 
   - Як користувач, я хочу бачити список ігор, щоб вибрати потрібну.
   - Як користувач, я хочу залишати нотатки та відмічати проходження.
4. **Архітектура та стек:** Flutter (Dart), віджети Material, управління станом (setState).
5. **Тестування та CI/CD:** Автоматизація збірки через GitHub Actions, перевірка лінтером, UI-тести.
6. **Демонстрація:** Демонстрація роботи додатку.
7. **Висновки:** Що реалізовано успішно, технічний борг та плани на майбутнє.
