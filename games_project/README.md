Game Diary (Щоденник Ігор)
Це веб-додаток для каталогізації відеоігор. Користувачі можуть реєструватися, додавати ігри до різних списків (Пройдені, Хочу пограти, Чекаю, Закинув) та оцінювати їх.

Технології
PHP 8.2
MySQL 8.0
HTML/CSS
Docker & Docker Compose
Запуск проєкту (через Docker)
Переконайтеся, що у вас запущений Docker Desktop.
Відкрийте термінал у папці з проєктом.
Виконайте команду для запуску контейнерів: docker compose -p gametracker up -d
Доступ до сервісів
Веб-додаток: http://localhost:8080
Панель бази даних (phpMyAdmin): http://localhost:8081
Користувач: root
Пароль: secret
База даних: games_db
